## What I'm Building Right Now

### Expense tracker · [live](https://gastos.alejandrocordoba.es/demo)

Personal expense tracker in production: budgets with email alerts, recurring expenses created by a
daily Celery task, CSV export and monthly summaries. Django REST Framework API
([code](https://github.com/SEDEBE/expense-tracker-api)), React + TypeScript frontend
([code](https://github.com/SEDEBE/expense-tracker-web)) and a VPS with Docker Compose, Caddy and
deployment from GitHub Actions ([code](https://github.com/SEDEBE/portfolio-infra)).
More at [alejandrocordoba.es](https://alejandrocordoba.es).

### SplitUp (TFG)

Aplicación de reparto de gastos en grupo.  
Core en Java, persistencia con MySQL usando Hibernate/JPA y documentación viva (README, Roadmap y recap técnico).

### Odoo 18 + Infraestructura Docker

Instancias de Odoo dockerizadas, Nginx como proxy inverso y monitorización de contenedores con Prometheus, Grafana y cAdvisor.
